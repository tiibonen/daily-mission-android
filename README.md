# Daily Mission Android Widget

A tiny Android home-screen widget with five tappable daily checkboxes, a rotating exercise, and a rotating motivational message.

## Checklist
- No treats
- Normal food
- Daily movement
- Drink water
- Read today's mindset

The widget resets naturally each calendar day and changes the exercise/message daily.

## Build without Android Studio
Push this project to a GitHub repository. The included GitHub Actions workflow builds the debug APK. In GitHub: **Actions → Build Daily Mission APK → Run workflow** (or push to `main`). When it finishes, open the workflow run and download the `daily-mission-apk` artifact. Unzip it and install `app-debug.apk` on Android.

After installation: long-press the Android home screen → Widgets → Daily Mission → add it to the home screen.
